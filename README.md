## 🚀 Projeto em destaque

### 🏭 Estação de Bombeamento Industrial — CODESYS

Projeto de controle, supervisão e simulação de uma estação de bombeamento industrial desenvolvido com **CODESYS, Ladder Logic, Structured Text e WebVisu**.

O projeto implementa:

- Operação manual e automática;
- Controle de bomba;
- START, STOP e RESET;
- Permissivos e intertravamentos;
- Detecção e retenção de falhas;
- Tratamento de inconsistência entre sensores;
- Simulação do nível do tanque;
- Contador de ciclos;
- Horímetro;
- Interface HMI através de WebVisu;
- Testes funcionais documentados.

🔗 **[Ver projeto no GitHub](https://github.com/rapha0311/estacao-bombeamento-industrial)**
